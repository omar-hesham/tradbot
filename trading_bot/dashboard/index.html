How It Works

1
Document IngestionYou or an AI agent adds a document. It is split into 500-word chunks and each chunk gets a vector embedding via Ollama (bge-m3).
2
Human Review GateAll documents land as Pending. They are invisible to the AI until you Approve. This prevents hallucinations from poisoning context.
3
Semantic RetrievalBefore each agent run, the bot embeds its query and finds the top-3 semantically similar chunks from approved documents using cosine similarity.
4
Context InjectionRetrieved chunks are injected into the AI prompt as historical advisory context — explicitly not treated as live facts. The agent defers to real-time market data.
